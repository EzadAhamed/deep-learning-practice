# Deep Learning Practice

This repository contains deep learning experiments and notebook-based practice covering common neural network architectures.

## Topics Covered
- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)

## Main Files
- `Ann.ipynb`
- `CNN (1).ipynb`
- `RNN.ipynb`

## Requirements
- Python 3.9+
- Jupyter Notebook or JupyterLab
- TensorFlow or PyTorch
- NumPy
- pandas

## Installation
```bash
git clone https://github.com/EzadAhamed/deep-learning-practice.git
cd deep-learning-practice
pip install jupyter tensorflow numpy pandas
```

## Usage
```bash
jupyter notebook
```

Open the notebook files in the browser and run the cells to explore the models.

## Notes
This repo is intended for practice, experimentation, and learning deep learning concepts.
